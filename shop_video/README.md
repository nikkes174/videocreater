# UnlimitSub video ads

Изолированный проект для вертикальной видеорекламы на Remotion. Существующий Python-генератор и его зависимости проект не использует.

## Параметры видео

- Формат кадра: 1080 × 1920, вертикальное 9:16.
- Частота: 30 FPS.
- Экспорт: MP4 / H.264 / `yuv420p`.
- Обычная длительность будущих рекламных композиций: 20 секунд; допустимый диапазон для роликов — 15–20 секунд.
- Безопасная область: 250 px сверху, 350 px снизу и 90 px по горизонтали.
- Звук пока не используется.

Единые параметры находятся в `src/config/video.ts`. Тестовая композиция `UnlimitSubTest` длится 3,5 секунды (105 кадров) и тоже получает размеры и частоту кадров из `VIDEO_CONFIG`.

## Тестовый логотипный интро-ролик

Композиция использует исходный прозрачный логотип `public/assets/unlimitsub-logo.png`, не заменяя его текстом и не перекрашивая изображение.

- Кадры 0–12: тёмный графитовый фон и слабое бирюзовое свечение.
- Кадры 12–36: логотип открывается движущейся слева направо световой полосой.
- Кадры 36–72: поверх оригинала проходит мягкое металлическое отражение, ограниченное альфа-формой логотипа.
- Кадры 72–104: камера плавно приближает логотип до максимальной ширины 850 px; свечение слегка усиливается, затем изображение плавно уходит в чёрный.

Анимация считается по номеру кадра через Remotion `useCurrentFrame()` и `interpolate()`. Переиспользуемый компонент `src/components/LogoReveal.tsx` принимает `logoSrc`, `revealStart`, `revealDuration`, `glowIntensity`, `sweepWidth` и `zoomAmount`.

`LogoReveal` также принимает `showBackground` (по умолчанию `true`). При `false` фоновые слои заставки не рисуются; логотип, световой проход, металлические отражения и push-in остаются, а финальное исчезновение затрагивает только логотип.

## Заставка поверх готового видео

Композиция `UnlimitSubLuxuryIntro` использует готовый `public/assets/one.mp4` в качестве видеофона и `LogoReveal` с прозрачной подложкой. Исходный файл был 1280 × 720, 25 FPS, 7,96 секунды, без аудиодорожки. Центрированный режим `cover` сохраняет пропорции и кадрирует по горизонтали, оставляя центральный световой проход в кадре Stories. Для 3,5-секундной композиции видео хватает без зацикливания.

Скопированный файл хранится в `public/assets/one.mp4`; корневой оригинал не изменён. Создать и проверить ролик можно командами:

```powershell
npm run render:luxury-intro
npm run verify:luxury-intro
```

Результат: `output/unlimitsub_luxury_intro.mp4` (1080 × 1920, 30 FPS, H.264, `yuv420p`, 105 кадров).

## Установка

Требуется Node.js. Из этой папки выполните:

```powershell
npm install
```

Remotion CLI устанавливает собственные бинарные файлы для рендера; системный FFmpeg и Python-пакеты этому проекту не нужны.

## Навыки Codex

Внутри `shop_video/` выполните команду из официальной инструкции Remotion:

```powershell
npx remotion skills add
```

Она устанавливает актуальные Remotion Agent Skills в `shop_video/.agents/skills`, включая рекомендации для создания композиций, анимации, предпросмотра и рендеринга. Codex загружает проектные навыки из текущей папки и её родителей, поэтому для работы с этим проектом запускайте Codex с рабочей папкой `shop_video/`.

Remotion поддерживает работу с Codex. Для анимации FlyingWords локально перенесены исходная композиция и минимальный набор нужных фикстур Video Shotcraft; лицензия Apache-2.0 и атрибуция находятся в `src/vendor/videoShotcraft/LICENSE` и `THIRD_PARTY_NOTICES.md`. Отдельные аудио- и медиаматериалы Shotcraft не включены. Awesome Opus использован только как каталог визуальных примеров; права на размещённые ролики и промпты остаются у их авторов.

## Remotion Studio и предпросмотр

Запустите Studio:

```powershell
npm run dev
```

В браузере выберите композицию `UnlimitSubTest` и просмотрите анимацию по кадрам. Также можно открыть видео после экспорта в любом видеоплеере.

## Экспорт MP4

Создайте тестовый файл:

```powershell
npm run render:logo
```

Файл будет сохранён как `output/logo_reveal_preview.mp4`. Команда `npm run render:test` остаётся совместимым псевдонимом. `remotion.config.ts` применяет кодек и pixel format из `VIDEO_CONFIG` для каждого экспорта, а также задаёт lossless PNG-кадры и цветовое пространство BT.709.

Проверьте готовый файл:

```powershell
npm run verify:logo
```

Проверка использует `ffprobe`, поставляемый с Remotion, и завершается ошибкой при несовпадении контейнера, кодека, разрешения, FPS, pixel format, количества кадров или длительности. Ожидаются MP4 / H.264 / `yuv420p`, 1080 × 1920, 30 FPS, 105 кадров и 3,5 секунды. `npm run verify:test` — совместимый псевдоним этой проверки.

## FlyingWords и сцена услуг

Добавлены три самостоятельные композиции, сохраняющие исходную механику Video Shotcraft: точечную перспективу, golden-angle размещение, движение по глубине, 10 приближающихся колец, 56 экранных световых следов, roll и жизненный цикл слов.

- `FlyingWordsOriginal`: исходная композиция 1920 × 1080, 30 FPS, 6 секунд.
- `FlyingWordsVertical`: адаптация пространства под 1080 × 1920 с оригинальными словами для проверки туннеля.
- `FlyingServicesScene`: вертикальная версия на 5 секунд со словами и цветами UnlimitSub и неподвижным русским слоганом.

Рендеринг и проверка:

```powershell
npm run render:flying-original
npm run verify:flying-original
npm run render:flying-vertical
npm run verify:flying-vertical
npm run render:flying-services
npm run verify:flying-services
```

Проверки подтверждают MP4/H.264, `yuv420p`, 30 FPS, ожидаемый размер кадра, число кадров и длительность. Результаты сохраняются в `output/flying_words_original.mp4`, `output/flying_words_vertical.mp4` и `output/flying_services_v2.mp4`.

## Оригинальная Basic3DScene Video Shotcraft

`ShotcraftBasic3DOriginal` — локальный оригинал композиции Basic3DScene, 1920 × 1080, 30 FPS, 225 кадров (7,5 секунды). Компонент и целиком необходимые фикстуры скопированы в `src/vendor/videoShotcraft/demos/`; сцена использует исходную математику и оформление без изменений.

## Фирменная сцена UnlimitSub Basic3D

`UnlimitSubBasic3D` — локальная фирменная копия той же постановки, 1920 × 1080, 30 FPS, 225 кадров (7,5 секунды). Изменены только палитра, карточки, бренд и финальный слоган; оригинальная композиция и глобальные фикстуры Video Shotcraft остаются без изменений.

```powershell
npm run render:unlimitsub-basic3d
npm run verify:unlimitsub-basic3d
```

```powershell
npm run render:shotcraft-basic3d
npm run verify:shotcraft-basic3d
```

Контактный лист сохраняется в `output/shotcraft_basic3d_contact.png`, а видео — в `output/shotcraft_basic3d_original.mp4`. Атрибуция и Apache-2.0 указаны в `THIRD_PARTY_NOTICES.md`.

## Добавление рекламных сцен

1. Создайте компонент сцены в `src/scenes/` и используйте `useCurrentFrame()`, `useVideoConfig()` и `interpolate()` для воспроизводимой анимации.
2. Размещайте значимые элементы внутри безопасной области из `VIDEO_CONFIG.safeArea`.
3. Добавьте сцену в `src/Root.tsx` как `Composition`, используя ширину, высоту и FPS из `VIDEO_CONFIG`. Для стандартного ролика на 20 секунд задайте `durationInFrames={VIDEO_CONFIG.durationSeconds * VIDEO_CONFIG.fps}`; тестовые сцены могут быть короче.
4. Положите локальные изображения и видео в `public/assets/` и подключайте их через `staticFile()`.
5. Перед передачей MP4 выполните экспорт и подходящую команду `verify:*`; для новой длительности передайте ожидаемые кадры и секунды скрипту `scripts/verify-output.mjs` или добавьте отдельную npm-команду.

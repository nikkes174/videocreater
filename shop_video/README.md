# UnlimitSub video ads

Изолированный проект для вертикальной видеорекламы на Remotion. Существующий Python-генератор и его зависимости проект не использует.

## Параметры видео

- Формат кадра: 1080 × 1920, вертикальное 9:16.
- Частота: 30 FPS.
- Экспорт: MP4 / H.264 / `yuv420p`.
- Обычная длительность будущих рекламных композиций: 20 секунд; допустимый диапазон для роликов — 15–20 секунд.
- Безопасная область: 250 px сверху, 350 px снизу и 90 px по горизонтали.
- Звук пока не используется.

Единые параметры находятся в `src/config/video.ts`. Первая композиция `UnlimitSubTest` намеренно длится 3 секунды и использует те же размер кадра и FPS.

## Установка

Требуется Node.js. Из этой папки выполните:

```powershell
npm install
```

Remotion CLI устанавливает собственные бинарные файлы для рендера; системный FFmpeg и Python-пакеты этому проекту не нужны.

## Навыки Codex

Внутри `shop_video/` выполните команду из официальной инструкции Remotion:

```powershell
npx remotion skills add
```

Она устанавливает актуальные Remotion Agent Skills в `shop_video/.agents/skills`, включая рекомендации для создания композиций, анимации, предпросмотра и рендеринга. Codex загружает проектные навыки из текущей папки и её родителей, поэтому для работы с этим проектом запускайте Codex с рабочей папкой `shop_video/`.

Remotion поддерживает работу с Codex. Video Shotcraft изучен как справочник техник: в тесте применены сдержанный бренд-ревил, мягкий акцентный свет и едва заметное движение камеры. Код и медиаматериалы Shotcraft не копировались. Awesome Opus использован только как каталог визуальных примеров; права на размещённые ролики и промпты остаются у их авторов.

## Remotion Studio и предпросмотр

Запустите Studio:

```powershell
npm run dev
```

В браузере выберите композицию `UnlimitSubTest` и просмотрите анимацию по кадрам. Также можно открыть видео после экспорта в любом видеоплеере.

## Экспорт MP4

Создайте тестовый файл:

```powershell
npm run render:test
```

Файл будет сохранён как `output/test.mp4`. `remotion.config.ts` применяет кодек и pixel format из `VIDEO_CONFIG` для каждого экспорта, а также задаёт lossless PNG-кадры и цветовое пространство BT.709.

Проверьте готовый файл:

```powershell
npm run verify:test
```

Проверка использует `ffprobe`, поставляемый с Remotion, и завершается ошибкой при несовпадении контейнера, кодека, разрешения, FPS, pixel format, количества кадров или длительности. Тестовая композиция должна содержать 90 кадров и длиться 3 секунды.

## Добавление рекламных сцен

1. Создайте компонент сцены в `src/scenes/` и используйте `useCurrentFrame()`, `useVideoConfig()` и `interpolate()` для воспроизводимой анимации.
2. Размещайте значимые элементы внутри безопасной области из `VIDEO_CONFIG.safeArea`.
3. Добавьте сцену в `src/Root.tsx` как `Composition`, используя ширину, высоту и FPS из `VIDEO_CONFIG`. Для стандартного ролика на 20 секунд задайте `durationInFrames={VIDEO_CONFIG.durationSeconds * VIDEO_CONFIG.fps}`; тестовые сцены могут быть короче.
4. Положите локальные изображения и видео в `public/assets/` и подключайте их через `staticFile()`.
5. Перед передачей MP4 выполните экспорт и `npm run verify:test` (для новых длительностей обновите профиль верификатора или добавьте отдельную команду проверки).
